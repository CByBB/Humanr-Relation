# human map

Mapa personal de personas, lugares, conexiones y recuerdos.

## Etapa 1

- Mapa mundial con marcadores y agrupación
- Perfiles de personas (CRUD) con ubicaciones múltiples
- Persistencia en `localStorage` con datos de demostración
- Importar / exportar JSON
- PWA instalable (caché básica del shell)

## Desarrollo

```bash
npm install
npm run dev
```

## Stack

React, TypeScript, Vite, Tailwind CSS, Leaflet (OpenStreetMap), `supercluster`.
